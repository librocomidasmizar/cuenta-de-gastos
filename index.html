    Cambiar contraseña

    Se descargará un archivo nuevo acceso.json. Súbelo a GitHub sustituyendo al anterior; hasta entonces sigue valiendo la contraseña antigua.

    Último paso: sube acceso.json

    Se ha descargado el archivo acceso.json. Va cifrado con tu contraseña: sin ella no sirve para nada.

    1. Entra en tu repositorio de GitHub de esta app.
    2. Pulsa Add file → Upload files y arrastra acceso.json (al lado de index.html).
    3. Pulsa Commit changes. En un par de minutos, cualquier dispositivo solo te pedirá la contraseña.
